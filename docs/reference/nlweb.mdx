`leadtype/nlweb` makes your docs site answer [NLWeb](https://nlweb.ai)
natural-language queries. It has two halves:

- **Runtime**: `createAskHandler()` mounts a Web-standard `/ask` endpoint over
  the generated artifacts — list-mode answers backed by the same search index
  the [docs MCP server](/docs/reference/mcp) uses. No LLM, no new content
  surface.
- **Generate-time**: with `agents.nlweb.enabled`, `leadtype generate` emits a
  schema.org JSONL feed (`/feeds/schema.jsonl`), a `/schema-map.xml` that lists
  it, and a `Schemamap:` directive in robots.txt so retrieval systems can find
  the feeds.

## Mount the /ask endpoint

```ts
// app/ask/route.ts (Next App Router)
import { createAskHandler } from "leadtype/nlweb";

const handler = createAskHandler({ artifacts: "./public" });
export const GET = handler;
export const POST = handler;
```

Pass `onError` to send server-side failures to your host logger or error
tracker. The callback receives the original error before the HTTP response is
sanitized. A promise it returns is awaited before the response is sent, so an
async flush completes first and a slow reporter delays the response.

The handler accepts the NLWeb request shapes — `?query=` params, a flat JSON
body, or the `{ query: { text }, prefer: { streaming } }` document. JSON request
bodies are limited to 16 KiB. The handler answers with:

```json
{
  "query_id": "…",
  "_meta": { "response_type": "answer", "version": "0.55" },
  "results": [
    {
      "url": "https://example.com/docs/quickstart",
      "name": "Quickstart",
      "site": "example.com",
      "score": 12.4,
      "description": "Install and configure the package.",
      "schema_object": { "@type": "TechArticle", "…": "…" }
    }
  ]
}
```

Streaming is opt-in: request it with `prefer.streaming: true`, `?streaming=1`,
or an `Accept: text/event-stream` header and the handler responds with SSE
`start` / `result` / `complete` events. (NLWeb defaults to streaming; leadtype
defaults to the JSON document so plain fetches and scanners get what they
expect.)

`mode=summarize` / `mode=generate` need an LLM and are not implemented —
queries always answer in list mode.

## Failure responses

Every non-2xx `/ask` response is JSON — an NLWeb-shaped envelope with a
leadtype-defined `error` extension — except the bodyless `204` answer to an
`OPTIONS` preflight. Failures stay JSON even when the request asked for
streaming.

```json
{
  "query_id": "…",
  "_meta": { "response_type": "failure", "version": "0.55" },
  "error": {
    "code": "missing_query",
    "message": "Missing query.",
    "resolution": "Pass query in the URL or JSON request body."
  },
  "results": []
}
```

`error`, `error.code`, and `error.resolution` are leadtype extensions to the
NLWeb response shape. The code is stable — branch on it rather than on the
message. Codes are exported as `NLWEB_ERROR_CODES` (typed as
`NlwebErrorCode`), and the response body is typed as `NlwebAskResponse`, a
union of `NlwebAskAnswer` and `NlwebAskFailure`. Narrow it with
`"error" in body`.

| Code | Status | Returned when |
| --- | --- | --- |
| `invalid_json` | 400 | The request body is non-empty and is not parseable JSON. |
| `invalid_request` | 400 | The body parses but is not an `/ask` document — not a JSON object, or `query`/`query_id` of the wrong type. |
| `request_too_large` | 413 | The JSON request body exceeds the 16 KiB limit. |
| `missing_query` | 400 | No query in the URL or the body. |
| `method_not_allowed` | 405 | A method other than `GET`, `POST`, or `OPTIONS`. The response keeps its `Allow` header. |
| `artifacts_unavailable` | 500 | The generated docs artifacts are missing, unreadable, or invalid — usually `leadtype generate` has not run where the handler is deployed, or its output is stale or incomplete. |
| `internal_error` | 500 | Anything else. |

`resolution` is a short recovery hint for the caller. Server-side detail —
stack traces, filesystem paths, the directory the handler looked in — never
reaches the response body, so `artifacts_unavailable` and `internal_error`
carry generic guidance. Pass `onError` to route the original error to your
server logs or error tracker.

An empty `POST` body is not an error: a `POST` may carry the whole request in
URL params. A URL `query_id` is echoed on answers and every failure. For
`POST`, a body `query_id` is also accepted and takes precedence. Unsupported
methods are rejected without reading their bodies, so their `405` response can
only use the URL value. When no ID is supplied, the handler mints one.

## Emit the schema feeds

```ts
// docs/docs.config.ts
agents: {
  nlweb: { enabled: true },
},
```

`leadtype generate` then writes `/feeds/schema.jsonl` (one schema.org
`TechArticle` per docs page), `/schema-map.xml` listing the feed, and adds
`Schemamap: <baseUrl>/schema-map.xml` after the `Sitemap:` line in robots.txt.
The root `llms.txt` also links the `/ask` endpoint under `## Agent Interfaces`. Set `agents.nlweb.endpoint` if you mount the handler somewhere
other than `/ask`.

Hosts that regenerate robots.txt at request time pass the directive through
`createRobotsTxtResponse({ schemamapUrlPath: "/schema-map.xml" })`.
